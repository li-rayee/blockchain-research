# Meme 币投资研究与代币经济学建模

配套代码部分，配套研究报告见 `report.pdf`。

没把它写成炒币笔记，而是用可计算的代币经济学模型，把三种典型 Meme 币的价值逻辑摊开对比：

| 币种 | 经济模型 | 核心叙事 | 投资逻辑 |
|---|---|---|---|
| Dogecoin | 适应性通货膨胀，无限供应加固定年增发 | 从网络玩笑变成支付货币的金融现象 | 类商品货币，看流通增长和通胀谁跑得快 |
| Shiba Inu | 结构性通缩，超发加交易销毁加多代币生态 | 草根反击中搭起 DeFi 生态 | 生态成败的期权，盯着 Shibarium 进展 |
| Pepe | 固定供应，总量锁定、无销毁无生态 | 纯粹社群共识的博弈容器 | 纯情绪和趋势交易，博傻试验场 |

## 模型与代码

### `dogecoin_inflation.py` —— 适应性通胀模型
每年固定增发约 52.6 亿枚 DOGE，初始流通 142.67 亿枚，模拟 30 年。流通量线性增长，通胀率随时间双曲线衰减，再和比特币（固定 2100 万上限、每四年减半）做对数坐标对比。

关键结果（脚本实测）：初始通胀率 3.68%，30 年后衰减到 1.78%；30 年后流通量约 300.35 十亿枚；年均通胀衰减 0.063% 每年，整体上是从高通胀往低通胀动态过渡。

### `shiba_deflation.py` —— 结构性通缩模型
初始 589 万亿枚，按日交易量乘销毁率乘 365 估算年销毁量，模拟 20 年，画出累计销毁量增长曲线、年通缩率和剩余流通占比。

关键结果（脚本实测）：20 年后流通量约 520.9 万亿枚，累计销毁 68.1 万亿枚；剩余流通占比 88.4%；平均年通缩率 0.611%。

### `pepe_market_simulation.py` —— 固定供应博弈市场
总量锁定 420.69 万亿枚，没有内生价值机制，用事件驱动的随机游走刻画价格。内置六个关键事件——交易所上线、大户抛售、名人提及等等。输出价格走势、日收益率分布（肥尾）、价格-交易量散点、市值、持有者增长、价格自相关性（随机游走检验）。

关键结果（脚本实测，seed=42 可复现）：平均日波动率 43.79%；最大单日涨幅 +465.14%，最大单日跌幅 −92.23%；模拟期末价格较初始下跌约 99.9%，没有内生价值支撑，归零风险最高。

## 运行

```bash
pip install -r requirements.txt
python dogecoin_inflation.py      # 生成 dogecoin_inflation.png
python shiba_deflation.py         # 生成 shiba_deflation.png
python pepe_market_simulation.py  # 生成 pepe_market_simulation.png
```

中文标签依赖系统里的中文字体（Windows 默认 SimHei）。遇上没装中文字体的 Linux 服务器，会回退到 DejaVu Sans，标题中文显示成方框，数值计算和图片布局不受影响。
